## transportfever3-balance-improvements
Minor balance improvements that should really be in the base game

# Changes:
- Standard track is updated to run at 200 km/h, so trains like the Pioneer Zephyr, Metroliner, AEM-7, and El-18, which aren't high speed trains, don't require high speed track to take full advantage of them.

- High speed tracks now unlock in 1964 with the Shinkansen 0 Series instead of 1980, because otherwise it is completely unusable

- The Avelia Liberty now runs at 300 km/h, its designed for 300, the French version goes 300, you shouldn't be punished because the NEC isn't proper HSR

# Compatibility:
Should be compatible with almost all other mods, the mod scripts in the updated values and doesn't change base game files
Can be safely added to save games
